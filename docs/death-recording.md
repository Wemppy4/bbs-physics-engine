# Рэгдолл при смерти

Автоматическая запись смерти принадлежит BBS Physics Engine и не требует BBSFP.
Движок нужен на клиенте и сервере, вместе с BBS 2.7.

1. У жертвы включить «Рэгдолл при смерти». Для стандартных кубических player-форм
   это также подготавливает разметку и включает игровое тело актёра.
2. Начать обычную игровую запись BBS за другого актёра (или за саму жертву).
3. После смертельного урона на дорожке жертвы появится «Смерть от удара».
   Поддерживаются меч, рука, снаряды, падение, огонь и другие серверные причины.
4. Остановить запись и воспроизвести фильм. В ручном режиме физики выполнить расчёт.

Смерть без источника направленного удара освобождает рэгдолл без дополнительного
толчка. Для нестандартных моделей нужна собственная физическая разметка.
Повторное воспроизведение не записывает новые смерти. Чистая запись редакторских
каналов позы не считается игровым дублем. Запись с управлением игроком в редакторе
BBSFP также поддержана, но сам BBSFP для обычной записи BBS не нужен.

Клип хранится в фильме, допускает перенос, отключение и запекание. Выключение
переключателя прекращает захват новых смертей, но не удаляет прежние клипы.
Смерть записываемого игрока привязывается к его реплею; смерть другого актёра —
к реплею жертвы. Автоматические события прежнего дубля заменяются в записанном
диапазоне. Запись с ненулевого кадра использует смещение начала дубля.

## Point Blank

BBSFP нужен только для передачи точной точки и направления попадания Point Blank.
Без него общий обработчик всё равно фиксирует смерть, используя центр тела.
API `bbs_physics:death_api = 2`: интеграция задаёт временный `DeathCapture.Impact`
для конкретной жертвы через `setImpact`, затем обязательно восстанавливает прежнее
значение в `finally`. Она не отправляет пакеты и не создаёт клипы самостоятельно.
При обновлении совместной установки обновить оба аддона.

Сборка и headless-проверки прошли. Пользователь подтвердил работу записанной смерти
в мире и объяснение поведения редактора включённым ручным расчётом. Остальные
причины смерти и все варианты повторного дубля отдельно в игре не проверены.
